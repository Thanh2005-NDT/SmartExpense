SmartExpense - Personal Expense Management Application
SmartExpense is an Android application designed to help users manage their personal finances efficiently. The application allows users to record daily expenses, categorize transactions, monitor spending habits, and visualize financial statistics through interactive charts.
Features
User Management
•	User registration and login
•	Session persistence using SharedPreferences
•	Personalized expense tracking
Expense Management
•	Add, edit, delete, and view expenses
•	Categorize expenses by type
•	Record transaction details and notes
•	View transaction history
Search & Filter
•	Search expenses by keyword
•	Filter expenses by date, month, year, and category
•	Sort transaction records for easier analysis
Financial Statistics
•	Pie Chart visualization of spending categories
•	Bar Chart analysis of expenses over time
•	Real-time dashboard updates
•	Spending trend monitoring
Budget Control
•	Budget management
•	Expense tracking against predefined budgets
•	Spending alerts and notifications
Data Export
•	Export expense reports to CSV files
•	Local data backup support
